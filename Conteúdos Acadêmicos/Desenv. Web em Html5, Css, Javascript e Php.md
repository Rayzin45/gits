Métodos Get e Post:

Método Get:
> Os dados são anexados no endereço;
Método Post:
> Os dados são enviados no corpo mensagem;
> O endereço não é alterado.
Observação: é importante ficar atento quanto ao método de envio.

As tecnologias

> HTML
    Características
    HTML: Linguagem de Marcação de Hipertexto;
    Estruturar páginas web;
    Embora HTML 5 tenha alguns recursos para acabamento, deve-se utilizar o CSS para este fim;
    HTML tem diversas tags prontas para uso;
    CSS
    HTML é executado nos navegadores;
    Tem sintaxe característica;

> CSS 
    Características
    CSS é utilizado para o acabamento de páginas web;
    Há diferentes formas de utilização de CSS;
    Mais eficiente, especialmente para portais com várias páginas com mesma identidade visual;

> JavaScript
Características
JavaScript é uma linguagem de programação;
Pode ser utilizada para diferentes propósitos;
Pode ser utilizada para alterar a parte comportamental de páginas web;
Utilizando eventos, como clique do mouse, pode realizar diversas ações;



> PHP: uma linguagem de programação server side
    Características
    PHP: Hypertext Preprocessor;
    É amplamente usada;
    Linguagem de script open source;
    Os scripts são executados no lado servidor;
    O resultado da execução do PHP no servidor é retornado ao navegador do cliente;
    Os arquivos PHP podem conter texto, HTML, CSS, JavaScript e PHP;
    É possível gerar conteúdo dinamicamente;
    É possível lidar com dados de formulários, entre outros recursos.
