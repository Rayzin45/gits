Diagramas estruturais

Mostram como o sistema é organizado.

Diagrama	Para que serve
1. Classes	Mostra classes, atributos, métodos e relacionamentos. Muito usado em POO.
2. Objetos	Mostra instâncias das classes em determinado momento.
3. Componentes	Mostra os componentes/módulos de software e suas dependências.
4. Estrutura Composta	Mostra a estrutura interna de uma classe ou componente.
5. Pacotes	Organiza classes e outros elementos em grupos/pacotes.
6. Implantação (Deployment)	Mostra onde o sistema é executado: servidores, dispositivos, máquinas etc.
7. Perfil (Profile)	Permite adaptar/estender a UML para áreas específicas.
Diagramas comportamentais

Mostram o comportamento e funcionamento do sistema.

Diagrama	Para que serve
8. Casos de Uso	Mostra o que os usuários/atores podem fazer no sistema.
9. Atividades	Representa um fluxo de ações/processos.
10. Máquina de Estados	Mostra os estados pelos quais um objeto passa.
11. Sequência	Mostra a troca de mensagens entre objetos ao longo do tempo.
12. Comunicação	Mostra como objetos interagem entre si.
13. Visão Geral de Interação	Combina conceitos de atividades e interações.
14. Temporização (Timing)	Mostra mudanças de estado relacionadas ao tempo.
